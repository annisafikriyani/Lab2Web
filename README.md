B. Langkah - Langkah Praktikum 
    
    1. **Membuat Struktur Utama (Semantic HTML)**
    - Menggunakan tag `<header>`, `<nav>`, `<main>`, `<section>`, dan `<footer>` untuk menyusun struktur halaman web yang rapi dan terstruktur.

    2. **Membuat Navigasi Halaman**
    - Menambahkan menu navigasi (`<nav>`) berisi tautan internal (`#biodata`, `#form`) serta tautan ke `index.html`.

    3. **Menambahkan Elemen Multimedia (Video)**
    - Menampilkan video Mars Universitas Pelita Bangsa menggunakan tag `<video>` dari folder `media/marsupb.mp4`.

    4. **Membuat Tabel Data Mahasiswa**
    - Menampilkan informasi biodata mahasiswa (Nama, NIM, Tanggal Lahir, dll.) menggunakan tag `<table>`, `<thead>`, dan `<tbody>`.

    5. **Membuat Form Biodata & Validasi Input**
    - Membuat form interaktif menggunakan berbagai jenis elemen input:
        - Input Teks (`text`, `number` untuk NIM)
        - Input Tanggal (`date`)
        - Pilihan Dropdown (`<select>`)
        - Pilihan Tunggal & Jamak (`radio` dan `checkbox`)
        - Area Teks Panjang (`<textarea>`)
    - Menerapkan validasi dasar menggunakan atribut `required` pada bidang input wajib.
